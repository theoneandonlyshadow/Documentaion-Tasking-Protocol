# Documentaion Tasking Protocol [ Theory ]

Initially ideated as *Priority Tasking Request Protocol/Model*, is a service over the cloud that lets you train a *fairly intelligent LLM* on documentation of another *service*. This *service* could be GitHub's documentation to fetch contents of an API or as you wish. This *service* has to have a web URL. This *service* will be web scraped by our *fairly intelligent LLM* and is trained thoroughly. The LLM will access your codebase to create/read/update/delete contents of your codebase. Suppose in your codebase, you are using GitHub's v1 documentation that is present in these fuctions: foo, bar. v2 documentation of GitHub states that foo has major issues resolved while some builtin functions revoked and some new fuctions added. bar has very minor issues resolved while many builtin functions revoked and no new functions are added. The LLM that is already trained on v1 documentation and its changelogs will be trained on the new v2 documentation. When you allow this LLM to access your codebase, the LLM will automatically search through the entire codebase for the v1 documentation and will find the aforementioned functions (foo, bar). The LLM will now assess the severity of these functions and is ready to migrate to v2 documentation without breaking the codebase and all the while changing only the necessary parts of the codebase.
